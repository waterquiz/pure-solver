Remote Image Display API

A high-performance, secure REST API designed for automated programs, IoT devices, desktop utilities, and web servers to stream incoming images in real-time straight to your web dashboard.

5-Step Quick Start

STEP 1

Create API Key

Navigate to API Keys and generate a new key.

STEP 2

Copy API Key

Copy the PS_... key to your environment.

STEP 3

Send Image

Post multipart image data with X-API-Key header.

STEP 4

Open Dashboard

Have your browser open on /dashboard.

STEP 5

Live Display!

Image appears instantly via WebSocket without refresh.

Decoupled Architecture: Computer A vs Computer B

The sender program does NOT need to open a browser or interact with the dashboard:

Computer A (Headless Server / Python / Raspberry Pi / Edge Device):
POST image.png ➔ https://yourdomain.com/api/v1/images with X-API-Key
Central API Server:
Validates key ➔ Validates signature ➔ Stores file ➔ Emits WebSocket event
Computer B (Monitoring Station / Office Browser):
Connected to /ws/dashboard ➔ Receives instant event ➔ Renders image instantly!

API Authentication

Supply your API key in every request using the X-API-Key request header.

X-API-Key: PS_900a2dbb943ac30d39ba1993ca3614379a04bb

Alternative: Authorization: Bearer PS_... is also accepted. Anonymous image uploads are strictly forbidden.

API Key Security Rules

  • Never commit raw API keys to public GitHub repositories.
  • Never embed secret API keys in client-side public web scripts.
  • Keep keys in environment variables (.env).
  • If a key is accidentally exposed, immediately revoke it in the dashboard.
POST /api/v1/images

Form Data Parameters

Field Type Required Description
file Binary File Yes Image payload (PNG, JPEG, WEBP, GIF, BMP, TIFF up to 10MB)
filename String Optional Custom original filename override
client_id String Optional Identifier for origin device (e.g. "Security-Cam-West")
description String Optional Text caption or note describing the capture
metadata JSON / String Optional Custom telemetry or sensor payload

HTTP Status Codes

201 Created Success

Image verified, stored, and broadcasted to live dashboards.

401 Unauthorized INVALID_API_KEY

Missing, invalid, or revoked API key.

400 Bad Request INVALID_IMAGE

Corrupt file or unsupported magic byte signature.

413 Payload Too Large FILE_TOO_LARGE

Exceeds MAX_IMAGE_SIZE_MB (default 10 MB).

429 Too Many Requests RATE_LIMITED

Exceeded 100 requests / minute rate limit.

500 Server Error SERVER_ERROR

Internal server or storage exception.

# Install: pip install requests
import requests

API_URL = "http://localhost:8000/api/v1/images"  # Replace with your deployed domain
API_KEY = "YOUR_API_KEY"

def upload_image(image_path: str, client_id: str = "python-client"):
    headers = {
        "X-API-Key": API_KEY
    }

    with open(image_path, "rb") as img:
        files = {
            "file": (image_path, img, "image/png")
        }
        data = {
            "client_id": client_id,
            "description": "Uploaded via Python client"
        }

        response = requests.post(
            API_URL,
            headers=headers,
            files=files,
            data=data,
            timeout=30
        )

    response.raise_for_status()
    return response.json()

if __name__ == "__main__":
    result = upload_image("image.png")
    print("Upload Result:", result)
// JavaScript (Browser HTML Form or File Picker)
const API_URL = "http://localhost:8000/api/v1/images";
const API_KEY = "YOUR_API_KEY";

async function uploadImage(file) {
    const formData = new FormData();
    formData.append("file", file);
    formData.append("client_id", "web-browser");
    formData.append("description", "Uploaded from browser file picker");

    try {
        const response = await fetch(API_URL, {
            method: "POST",
            headers: {
                "X-API-Key": API_KEY
            },
            body: formData
        });

        const result = await response.json();
        console.log("Upload Success:", result);
        return result;
    } catch (error) {
        console.error("Upload Error:", error);
    }
}

using System;
using System.IO;
using System.Net.Http;
using System.Threading.Tasks;

class Program {
    static async Task Main() {
        var apiUrl = "http://localhost:8000/api/v1/images";
        var apiKey = "YOUR_API_KEY";
        var imagePath = "image.png";

        using var client = new HttpClient();
        client.DefaultRequestHeaders.Add("X-API-Key", apiKey);

        using var form = new MultipartFormDataContent();
        using var fileStream = File.OpenRead(imagePath);
        using var streamContent = new StreamContent(fileStream);

        form.Add(streamContent, "file", Path.GetFileName(imagePath));
        form.Add(new StringContent("csharp-client"), "client_id");

        var response = await client.PostAsync(apiUrl, form);
        var resultJson = await response.Content.ReadAsStringAsync();

        Console.WriteLine($"Status: {response.StatusCode}");
        Console.WriteLine($"Response: {resultJson}");
    }
}
// Java 11+ HttpClient with Multipart
import java.io.IOException;
import java.net.URI;
import java.net.http.*;
import java.nio.file.Files;
import java.nio.file.Path;

public class ImageUploader {
    public static void main(String[] args) throws IOException, InterruptedException {
        String apiUrl = "http://localhost:8000/api/v1/images";
        String apiKey = "YOUR_API_KEY";
        Path imagePath = Path.of("image.png");

        String boundary = "---" + System.currentTimeMillis();
        byte[] fileBytes = Files.readAllBytes(imagePath);

        StringBuilder body = new StringBuilder();
        body.append("--").append(boundary).append("\r\n");
        body.append("Content-Disposition: form-data; name=\"file\"; filename=\"image.png\"\r\n");
        body.append("Content-Type: image/png\r\n\r\n");

        byte[] headerBytes = body.toString().getBytes();
        byte[] footerBytes = ("\r\n--" + boundary + "--\r\n").getBytes();

        byte[] payload = new byte[headerBytes.length + fileBytes.length + footerBytes.length];
        System.arraycopy(headerBytes, 0, payload, 0, headerBytes.length);
        System.arraycopy(fileBytes, 0, payload, headerBytes.length, fileBytes.length);
        System.arraycopy(footerBytes, 0, payload, headerBytes.length + fileBytes.length, footerBytes.length);

        HttpClient client = HttpClient.newHttpClient();
        HttpRequest request = HttpRequest.newBuilder()
                .uri(URI.create(apiUrl))
                .header("X-API-Key", apiKey)
                .header("Content-Type", "multipart/form-data; boundary=" + boundary)
                .POST(HttpRequest.BodyPublishers.ofByteArray(payload))
                .build();

        HttpResponse response = client.send(request, HttpResponse.BodyHandlers.ofString());
        System.out.println("Status: " + response.statusCode());
        System.out.println("Response: " + response.body());
    }
}
package main

import (
	"bytes"
	"fmt"
	"io"
	"mime/multipart"
	"net/http"
	"os"
)

func main() {
	apiUrl := "http://localhost:8000/api/v1/images"
	apiKey := "YOUR_API_KEY"
	filePath := "image.png"

	file, err := os.Open(filePath)
	if err != nil { panic(err) }
	defer file.Close()

	body := &bytes.Buffer{}
	writer := multipart.NewWriter(body)
	part, err := writer.CreateFormFile("file", "image.png")
	if err != nil { panic(err) }
	io.Copy(part, file)
	writer.WriteField("client_id", "go-uploader")
	writer.Close()

	req, err := http.NewRequest("POST", apiUrl, body)
	if err != nil { panic(err) }
	req.Header.Set("Content-Type", writer.FormDataContentType())
	req.Header.Set("X-API-Key", apiKey)

	client := &http.Client{}
	resp, err := client.Do(req)
	if err != nil { panic(err) }
	defer resp.Body.Close()

	respBody, _ := io.ReadAll(resp.Body)
	fmt.Printf("Status: %s\nResponse: %s\n", resp.Status, string(respBody))
}

// Swift URLSession (iOS / macOS)
import Foundation

func uploadImage(imageURL: URL, apiKey: String) {
    let url = URL(string: "http://localhost:8000/api/v1/images")!
    var request = URLRequest(url: url)
    request.httpMethod = "POST"
    request.setValue(apiKey, forHTTPHeaderField: "X-API-Key")

    let boundary = UUID().uuidString
    request.setValue("multipart/form-data; boundary=\(boundary)", forHTTPHeaderField: "Content-Type")

    var data = Data()
    let imageData = try? Data(contentsOf: imageURL)

    data.append("--\(boundary)\r\n".data(using: .utf8)!)
    data.append("Content-Disposition: form-data; name=\"file\"; filename=\"image.png\"\r\n".data(using: .utf8)!)
    data.append("Content-Type: image/png\r\n\r\n".data(using: .utf8)!)
    if let img = imageData { data.append(img) }
    data.append("\r\n--\(boundary)--\r\n".data(using: .utf8)!)

    let task = URLSession.shared.uploadTask(with: request, from: data) { responseData, response, error in
        if let responseData = responseData, let json = String(data: responseData, encoding: .utf8) {
            print("Response:", json)
        }
    }
    task.resume()
}
// Kotlin / Android using OkHttp
import okhttp3.*
import okhttp3.MediaType.Companion.toMediaTypeOrNull
import okhttp3.RequestBody.Companion.asRequestBody
import java.io.File

fun uploadImage(file: File, apiKey: String) {
    val client = OkHttpClient()
    val mediaType = "image/png".toMediaTypeOrNull()
    val fileBody = file.asRequestBody(mediaType)

    val requestBody = MultipartBody.Builder()
        .setType(MultipartBody.FORM)
        .addFormDataPart("file", file.name, fileBody)
        .addFormDataPart("client_id", "android-device")
        .build()

    val request = Request.Builder()
        .url("http://localhost:8000/api/v1/images")
        .addHeader("X-API-Key", apiKey)
        .post(requestBody)
        .build()

    client.newCall(request).execute().use { response ->
        println("Status: ${response.code}")
        println("Response: ${response.body?.string()}")
    }
}

Postman Configuration Guide

  1. Open Postman and create a new request.
  2. Set HTTP method to POST.
  3. Enter URL: https://yourdomain.com/api/v1/images
  4. In the Headers tab, add:
    Key: X-API-Key | Value: YOUR_API_KEY
  5. In the Body tab:
    • Select form-data
    • Add key: file, change type dropdown on the right from Text to File
    • Click Select Files and choose an image (image.png)
    • (Optional) Add key: client_id with text value postman-client
  6. Click Send. You will receive HTTP 201 Created with image URL and metadata!
